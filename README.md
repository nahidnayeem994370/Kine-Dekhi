# Kine dekhi

Kine dekhi is a mobile-friendly Bengali multi-category ecommerce storefront prototype.

## Current status
- Responsive homepage, category filters, product search, sample products, and client-side cart.
- Sample products/prices are illustrative only.
- No real order submission, customer data storage, admin login, or payment processing is enabled yet.

## Next steps
1. Create a separate Supabase project for Kine dekhi.
2. Design database tables and Row Level Security policies for products, categories, and orders.
3. Add secure admin authentication and product management.
4. Implement checkout and order tracking.
5. Integrate COD first, then an approved bKash/Nagad payment gateway using server-side verification.
6. Enable GitHub Pages and later connect a custom domain.

Never commit Supabase service-role keys or payment secrets to this repository.
